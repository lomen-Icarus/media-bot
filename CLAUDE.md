# media-bot — правила для работы над ботом

Бот вотермарок медиа-ВИШ: Telegram + МАКС, одно ядро. Подробности: `README.md`, решения — `docs/DECISIONS.md`, деплой — `docs/DEPLOY.md`, промт для ревью архитектуры — `docs/ARCHITECTURE_REVIEW_PROMPT.md`.
Отвечать владельцу по-русски, коротко и по делу; о сделанном — в формате «было → стало».

## Интерфейс
Правила пути человека — как в vish-bot (`CLAUDE.md` там): считать путь «было → стало», ежедневное — 1 действие, подписи словами человека, кнопка следующего шага — под результатом, обратимость. Главный путь здесь: прислал фото → получил файлы; ничего не должно добавлять к нему шагов.

## Постоянные правила
- Ядро (`src/core/`) не импортирует grammY и клиент МАКС — только интерфейс `Messenger`. Новая функция пишется один раз и работает в обоих мессенджерах.
- Качество: размер в пикселях, формат, глубина цвета, альфа, CMYK, EXIF/ICC — как у исходника; JPEG не ниже качества исходника и не ниже 92. Любая правка `src/image/` — с тестом в `test/image.test.ts`.
- Секреты — только `.env` / GitHub Secrets. В логах — только id и цифры, без имён и текстов. Репозиторий публичный.
- Миграции БД — только дописывать в конец `src/db/migrations.ts`.
- Без зависимостей с `node-gyp`: хостинг FrienWorld не собирает нативные модули (sharp и resvg — готовые бинарники, это можно).
- Перед пушем: `npm run typecheck`, `npm test`, `npm run build`.
