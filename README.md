# media-bot

Бот вотермарок для медиа-ВИШ. **Один бот — два мессенджера одновременно:** Telegram и МАКС, общая база и одинаковые экраны.

Прислал от 1 до 10 фото → получил те же файлы с вотермаркой: тот же размер в пикселях, тот же формат, качество не хуже исходника. Вотермарки лежат в базе бота, их добавляет админ; место, размер и прозрачность каждый выбирает сам, и бот это запоминает.

## Как пользоваться

| Задача | Путь |
|---|---|
| Поставить вотермарку (каждый день) | прислать фото **файлом** (📎 → Файл), до 10 за раз — **1 действие**, ответ — файлы + кнопки |
| Не понравилось место или размер | под результатом «📍 Место» → «↙️» — **2 нажатия**: бот переделает эту же пачку, старые файлы заменит новыми и запомнит выбор |
| Заранее выбрать вотермарку, место, размер, прозрачность | `/settings` или «⚙️ Настройки» → раздел → значение — **3 нажатия** |
| Добавить вотермарку в базу (админ) | ⚙️ → «🗂 Вотермарки в базе» → «➕» → прислать PNG файлом (подпись = название) |
| Пустить человека (админ) | человек пишет боту → админу приходит запрос → «✅ Пустить» — **1 нажатие** |

- **Места** — 9: углы, середины сторон, центр. Отступ от края — 3% короткой стороны фото.
- **Размер** — 10/15/20/30/45/60%: длинная сторона вотермарки в процентах от короткой стороны фото, поэтому на вертикальных и горизонтальных фото она одного размера.
- **Прозрачность** — 100/80/60/40/25%.
- Альбом собирается сам: бот ждёт 1,5 с тишины. Если прислать больше 10 фото, бот обработает их пачками по 10.

## Качество — что именно гарантируется

- Размер в пикселях не меняется. Поворот из EXIF применяется к пикселям, чтобы вотермарка не встала «боком», а тег поворота сбрасывается.
- Формат тот же: JPG → JPG, PNG → PNG, WebP, TIFF, AVIF.
- **JPEG** пересжимается с качеством исходника, которое бот определяет по таблице квантования, но не ниже 92. Субдискретизация цвета (4:4:4 / 4:2:0) и прогрессивность сохраняются.
- PNG и TIFF — без потерь. 16 бит остаются 16 битами, альфа-канал появляется, только если он был в исходнике.
- CMYK остаётся CMYK.
- EXIF (камера, дата, авторство), ICC-профиль и XMP сохраняются.
- Результат уходит **документом**, поэтому мессенджер его не пересжимает.
- ⚠️ Фото, отправленное в Telegram «как фото», а не файлом, Telegram сжимает ещё до бота. Бот такое обработает, но под результатом подскажет отправлять файлом.
- ❌ HEIC (iPhone) не поддерживается: в готовых сборках sharp нет декодера HEVC. На iPhone есть настройка «Камера → Форматы → Наиболее совместимый»; бот подсказывает это сам.
- Ограничения Telegram для ботов: скачать можно файл до 20 МБ, отправить — до 50 МБ.

## Как устроено

```
Telegram (grammY, long polling) ──┐                         ┌── sharp: renderWatermarked()
                                  ├─► App (src/core/app.ts) ─┤
МАКС (свой клиент, long polling) ─┘    одно ядро, экраны    └── SQLite: люди, настройки, вотермарки, счётчики
        ▲                               src/core/screens.ts
        └── Messenger: sendText / editText / sendFiles / deleteMessages
```

- `src/core/` — ядро, которое не знает про мессенджеры. Адаптеры переводят события в `onText / onFiles / onCallback` и выполняют ответы через интерфейс `Messenger` (`src/core/types.ts`).
- `src/tg/adapter.ts` — Telegram: альбом документов (до 10 файлов и до 50 МБ на запрос), удаление прошлого результата.
- `src/max/` — МАКС: клиент `api.ts` взят из vish-bot (там он работает в проде; корень НУЦ Минцифры подключён точечно). Long polling с запоминанием позиции.
- `src/image/` — вотермарка (`watermark.ts`) и определение качества JPEG (`jpeg.ts`).
- `src/core/batches.ts` — присланные оригиналы на диске хранятся `BATCH_TTL_HOURS` (6 ч), чтобы кнопки могли переделать пачку. Потом и после перезапуска они удаляются.
- `src/db/` — node:sqlite без нативных модулей; миграции только дописываются.

Человек в базе — пара (мессенджер, id). Админы и доступ задаются отдельно для Telegram и МАКС. Решения и причины — в `docs/DECISIONS.md`, деплой — в `docs/DEPLOY.md`.

## Разработка

```bash
npm install
cp .env.example .env     # BOT_TOKEN и/или MAX_BOT_TOKEN, TG_ADMIN_IDS / MAX_ADMIN_IDS
npm run typecheck && npm test && npm run build
npm run dev              # бот с автоперезапуском
```

Стек: Node.js 22, TypeScript, grammY, sharp (libvips, готовые бинарники без сборки), встроенный node:sqlite, undici, pino, zod, vitest.
